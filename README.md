# gouache-winter

A Claude Code look for the desktop and mobile apps: warm, gouache-painted paper colors in light and dark mode, painted message cards in a serif type, and a winter backdrop where snow falls on a cat with a lantern, a rabbit and a mouse standing either side of the chat column. Snow piles up along the bottom as the session's context window fills, and melts back after a compact.

## Install

At the prompt of a terminal session:

```
/plugin install gouache-winter --marketplace <owner>/<repo>
```

From a shell:

```
claude plugin install gouache-winter --marketplace <owner>/<repo>
```

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with `<owner>/<repo>`, then Add plugin.

The look is applied when a session starts; in a session that was already running, run `/reload-plugins` or start a new session. The terminal draws no theme.
